# PythonMachineLearning

## Description

This is a collection of projects I have done from the book titled **_Python Machine Learning By Example_** by Yuxi (Hayden) Liu.

### Software Installation and Environment Setup

The projects will use **_Python 3_**

- The book recommends to use the [Anaconda](https://www.anaconda.com/docs/main) or the [Miniconda](https://docs.conda.io/en/latest/) distributions. I used Miniconda to reduce the amount of storage needed for these projects.

Many of these projects use packages like:

- [NumPy](https://numpy.org/install)
- [SciPy](https://scipy.org)
- [scikit-learn](https://scikit-learn.org/stable/install)
- [TensorFlow](https://www.tensorflow.org/install)
- [PyTorch](https://pytorch.org/get-started/locally)
- [pandas library](https://pandas.pydata.org)

#### Project Environment

- Used to setup each the environment for each project

1. Create and environment called "pyml"

- conda create --name pyml python=3.10

2. Activate the environment titled "pyml"

- conda activate pyml

3. It should look something like this in the terminal:
   `(pyml) Users.../ ~ %`
